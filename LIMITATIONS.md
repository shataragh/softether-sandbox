# ⚠️ Known Limitations

Understand what doesn’t work yet, or isn’t intended for production.

| Limitation | Details |
|------------|---------|
| 🕑 Codespaces timeout | May disconnect after long inactivity |
| 🖥️ No GUI support | SoftEther Windows GUI not usable here |
| 📡 IPv6 | Not enabled by default |
| 🔐 Admin access | Required for `localhost:5555` usage |

## 💡 Suggestions

If you need GUI or persistent uptime, consider:
- Running on a personal VPS
- Dockerizing the setup for self-hosting
